# Modular Config Templates

Templates for each generated file. `{{placeholders}}` are filled from interview answers. Emit
syntax matched to the detected version — cross-check `hyprland-reference/references/deprecations.md`
(these templates use current syntax, verified against 0.5x: `shadow {}`/`blur {}` subcategories,
`master:new_status`, unified `windowrule`). Keep the grouping comments; they make the result
readable and easy to hand-edit.

---

## hyprland.conf (main entry — variables + sources)

```ini
# ----------------------------------------------------------------------------
# Hyprland config — generated by the hyprland-config plugin
# Target version: {{hypr_version}}
# Edit the sourced files below; this file just wires them together.
# ----------------------------------------------------------------------------

# Variables — $mainMod matches the official default config and tutorials
$mainMod     = {{mod}}
$terminal    = {{terminal}}
$menu        = {{launcher}}
$browser     = {{browser}}
$fileManager = {{filemanager_or_omit}}

# Sourced modules (order matters: env first, then colors so $accent/$bg are defined
# before looknfeel uses them)
source = ~/.config/hypr/env.conf
source = ~/.config/hypr/colors.conf
source = ~/.config/hypr/monitors.conf
source = ~/.config/hypr/input.conf
source = ~/.config/hypr/looknfeel.conf
source = ~/.config/hypr/binds.conf
source = ~/.config/hypr/windowrules.conf
source = ~/.config/hypr/autostart.conf
```

Use `$mainMod` (the official default's variable name), defaulting to `SUPER`. Omit
`$fileManager`/`$browser` variables if the user didn't pick those apps.

**`colors.conf` is not written by hand** — it is rendered by the rice engine from the chosen
palette (`~/.config/hypr-rice/palette.conf`), and defines `$accent $accent2 $bg $fg $surface
$muted` as Hyprland variables. It is sourced early so `looknfeel.conf` can use `$accent`/`$accent2`
for the border. Re-theming later (`/hyprland-config:theme-config`) just rewrites `colors.conf` from
the same palette — the rest of `hyprland.conf` never changes. See the SKILL's step 4 for how it's
scaffolded and rendered during generation.

```ini
# Environment — sourced first so later programs inherit these.

{{/if}}
{{#if cursor}}
env = XCURSOR_SIZE,24

{{/if}}
{{#if toolkit}}

env = GDK_BACKEND,wayland,x11
{{/if}}
{{#if qt_theme}}
env = QT_QPA_PLATFORMTHEME,qt6ct
{{/if}}
{{#if firefox_wayland}}
env = MOZ_ENABLE_WAYLAND,1
{{/if}}
```

(The `{{#if}}` blocks are authoring guidance — emit only the chosen lines, no template markers.)

## monitors.conf

```ini
# Monitors: NAME, RESOLUTION@REFRESH, POSITION, SCALE
# Real names: `hyprctl monitors`. Adjust if these are placeholders.
{{monitor_lines}}
# Fallback rule for any monitor not listed above:
monitor = , preferred, auto, 1
```

Examples of `{{monitor_lines}}`:

```ini
monitor = , preferred, auto, auto                   # single, auto (auto scale = HL picks, incl. fractional)
monitor = DP-1, 2560x1440@144, 0x0, 1               # primary, explicit scale 1
monitor = HDMI-A-1, 1920x1080@60, 2560x0, 1         # second, to the right
monitor = eDP-1, preferred, auto, 1.5               # laptop HiDPI, explicit fractional
```

The shipped default uses `monitor=,preferred,auto,auto` — `auto` scale lets Hyprland choose.
Use an explicit scale (`1`, `1.5`, `2`) only when the user wants to pin it.

## input.conf

```ini
input {
    kb_layout = {{kb_layout}}
    kb_variant =
    kb_options = {{kb_options_or_blank}}
    follow_mouse = 1
    sensitivity = 0          # libinput accel, -1.0 .. 1.0

    touchpad {
        natural_scroll = {{touchpad_natural_scroll}}
        disable_while_typing = true
        tap-to-click = {{touchpad_tap}}
        clickfinger_behavior = true
    }
}

# Touchpad gestures — 0.45+ keyword API (the shipped default ships this line)
{{#if touchpad}}
gesture = 3, horizontal, workspace
{{/if}}
```

Omit the `touchpad {}` block and the `gesture =` line entirely for desktops. On a target older
than 0.45, use a `gestures { workspace_swipe = true }` block instead (see `deprecations.md`).

## looknfeel.conf (general + decoration + animations + layout)

```ini
general {
    gaps_in = {{gaps_in}}
    gaps_out = {{gaps_out}}
    border_size = {{border_size}}
    # Palette-derived (default): $accent/$accent2 come from colors.conf, sourced above.
    # If the user chose a custom gradient in C6, substitute it here instead.
    col.active_border = $accent $accent2 45deg
    col.inactive_border = $surface
    layout = {{layout}}
    resize_on_border = true
    allow_tearing = false
}

decoration {
    rounding = {{rounding}}
    rounding_power = 2          # 0.5x+; omit on older targets
    active_opacity = {{active_opacity}}
    inactive_opacity = {{inactive_opacity}}

    blur {
        enabled = {{blur_enabled}}
        size = 3
        passes = 1
        vibrancy = 0.1696
    }

    shadow {
        enabled = {{shadow_enabled}}
        range = 4
        render_power = 3
        color = rgba(1a1a1aee)
    }
}

# Animation curves + targets mirror the shipped default (well-tuned). Drop the whole block or
# set enabled = false if the user chose "animations off".
animations {
    enabled = {{anim_enabled}}

    bezier = easeOutQuint,   0.23, 1,    0.32, 1
    bezier = easeInOutCubic, 0.65, 0.05, 0.36, 1
    bezier = linear,         0,    0,    1,    1
    bezier = almostLinear,   0.5,  0.5,  0.75, 1
    bezier = quick,          0.15, 0,    0.1,  1

    animation = global,        1, 10,   default
    animation = border,        1, 5.39, easeOutQuint
    animation = windows,       1, 4.79, easeOutQuint
    animation = windowsIn,     1, 4.1,  easeOutQuint, popin 87%
    animation = windowsOut,    1, 1.49, linear,       popin 87%
    animation = fadeIn,        1, 1.73, almostLinear
    animation = fadeOut,       1, 1.46, almostLinear
    animation = fade,          1, 3.03, quick
    animation = layers,        1, 3.81, easeOutQuint
    animation = layersIn,      1, 4,    easeOutQuint, fade
    animation = layersOut,     1, 1.5,  linear,       fade
    animation = workspaces,    1, 1.94, almostLinear, fade
}

{{layout_block}}   # dwindle {} or master {} per choice
```

For a "snappy" preference, scale the speeds down (e.g. multiply by ~0.6). For "off", set
`enabled = false` and you may drop the `animation =` lines.

Layout blocks:

```ini
dwindle {
    pseudotile = true
    preserve_split = true
}
```
```ini
master {
    new_status = master
    mfact = 0.55
}
```

Anim speed: smooth ≈ 7, snappy ≈ 4. If animations off, set `enabled = false` and the
`animation=` lines may be dropped.

## binds.conf

This follows the **official default scheme** (Q=terminal, C=close, R=menu, E=files, V=float,
M=exit) so muscle memory transfers. Use `$mainMod`. For an i3/sway-style scheme instead
(Return=terminal, Q=close, D=menu), offer it but default to this.

```ini
# Apps
bind = $mainMod, Q, exec, $terminal
bind = $mainMod, R, exec, $menu
bind = $mainMod, E, exec, $fileManager
bind = $mainMod, B, exec, $browser

# Window management
bind = $mainMod, C, killactive,
bind = $mainMod, M, exit,
bind = $mainMod, V, togglefloating,
bind = $mainMod, F, fullscreen,
bind = $mainMod, P, pseudo,                  # dwindle
{{#unless vim}}
bind = $mainMod, J, layoutmsg, togglesplit   # dwindle (split toggle is a layoutmsg)
{{else}}
bind = $mainMod, T, layoutmsg, togglesplit   # vim mode: J is focus-down, so togglesplit -> T
{{/unless}}

# Focus (arrows always; HJKL added in vim mode)
bind = $mainMod, left, movefocus, l
bind = $mainMod, right, movefocus, r
bind = $mainMod, up, movefocus, u
bind = $mainMod, down, movefocus, d
{{#if vim}}
bind = $mainMod, H, movefocus, l
bind = $mainMod, L, movefocus, r
bind = $mainMod, K, movefocus, u
bind = $mainMod, J, movefocus, d
{{/if}}

# Move windows
bind = $mainMod SHIFT, left, movewindow, l
bind = $mainMod SHIFT, right, movewindow, r
bind = $mainMod SHIFT, up, movewindow, u
bind = $mainMod SHIFT, down, movewindow, d

# Workspaces 1-10 (emit all ten explicitly; 0 = workspace 10)
bind = $mainMod, 1, workspace, 1
# ... through 0
bind = $mainMod SHIFT, 1, movetoworkspace, 1
# ... through 0
bind = $mainMod, mouse_down, workspace, e+1
bind = $mainMod, mouse_up, workspace, e-1

# Scratchpad (special workspace)
bind = $mainMod, S, togglespecialworkspace, magic
bind = $mainMod SHIFT, S, movetoworkspace, special:magic

# Mouse move/resize
bindm = $mainMod, mouse:272, movewindow
bindm = $mainMod, mouse:273, resizewindow

# Media & brightness (repeat + work when locked). -l 1 caps volume at 100%.
bindel = , XF86AudioRaiseVolume,  exec, wpctl set-volume -l 1 @DEFAULT_AUDIO_SINK@ 5%+
bindel = , XF86AudioLowerVolume,  exec, wpctl set-volume @DEFAULT_AUDIO_SINK@ 5%-
bindel = , XF86AudioMute,         exec, wpctl set-mute @DEFAULT_AUDIO_SINK@ toggle
bindel = , XF86AudioMicMute,      exec, wpctl set-mute @DEFAULT_AUDIO_SOURCE@ toggle
bindel = , XF86MonBrightnessUp,   exec, brightnessctl -e4 -n2 set 5%+
bindel = , XF86MonBrightnessDown, exec, brightnessctl -e4 -n2 set 5%-
{{#if playerctl}}
bindl = , XF86AudioNext,  exec, playerctl next
bindl = , XF86AudioPause, exec, playerctl play-pause
bindl = , XF86AudioPlay,  exec, playerctl play-pause
bindl = , XF86AudioPrev,  exec, playerctl previous
{{/if}}

# Screenshots (pick ONE branch based on the chosen tool)
{{#if hyprshot}}
bind = , Print, exec, hyprshot -m region
bind = $mainMod, Print, exec, hyprshot -m window
bind = $mainMod SHIFT, Print, exec, hyprshot -m output
{{else if grimblast}}
bind = , Print, exec, grimblast copy area
bind = $mainMod, Print, exec, grimblast copy active
bind = $mainMod SHIFT, Print, exec, grimblast copy screen
{{else}}
bind = , Print, exec, grim -g "$(slurp)" - | wl-copy
bind = $mainMod, Print, exec, grim - | wl-copy
{{/if}}

# Ecosystem binds (emit only for chosen tools; keys chosen to avoid the scheme above)
{{#if hyprlock}}bind = $mainMod, X, exec, hyprlock{{/if}}
{{#if hyprpicker}}bind = $mainMod SHIFT, P, exec, hyprpicker -a{{/if}}
{{#if wlogout}}bind = $mainMod SHIFT, M, exec, wlogout{{/if}}
{{#if cliphist}}bind = $mainMod SHIFT, V, exec, cliphist list | $menu | cliphist decode | wl-copy{{/if}}
```

Generate all ten workspace switch + move lines explicitly. The `{{#if}}`/`{{#unless}}`/`{{else}}`
markers are authoring guidance — emit only the chosen lines, never the markers. **Avoid binding
the same `MODS, KEY` twice** — note `C` is killactive in this scheme (don't reuse it for
clipboard), and in vim mode `J` is focus-down (togglesplit moves to `T`). The validator flags
duplicates.

## windowrules.conf

**0.53+ block form** (matches the shipped default). Includes two broadly-useful rules the
default ships (suppress maximize; fix XWayland drag focus):

```ini
# Generally desirable defaults (from the shipped config)
windowrule {
    name = suppress-maximize
    match:class = .*
    suppress_event = maximize
}
windowrule {
    name = fix-xwayland-drags
    match:class = ^$
    match:title = ^$
    match:xwayland = true
    match:float = true
    match:fullscreen = false
    match:pin = false
    no_focus = true
}

# Float common utility dialogs
windowrule {
    name = float-utilities
    match:class = ^(pavucontrol|nm-connection-editor|blueman-manager)$
    float = yes
}

# Picture-in-picture: float + pin
windowrule {
    name = pip
    match:title = ^(Picture-in-Picture)$
    float = yes
    pin = yes
}

# Idle inhibit while fullscreen (video/games)
windowrule {
    name = idleinhibit-fullscreen
    match:fullscreen = true
    idle_inhibit = fullscreen
}

# Layer blur for the bar/launcher (0.54 block form — match chosen tools)
{{#if waybar}}
layerrule {
    name = blur-waybar
    match:namespace = waybar
    blur = true
}
{{/if}}
{{#if launcher_is_layer}}
layerrule {
    name = blur-{{launcher_namespace}}
    match:namespace = {{launcher_namespace}}
    blur = true
}
{{/if}}
```

**`layerrule` is version-sensitive — do not emit `layerrule = blur, waybar` on 0.54.** That
single-line form is *rejected* on 0.54.3 (`invalid field blur: missing a value`) and fails the
whole reload; use the block form above. On **older targets (pre-0.53)** emit the single-line forms
instead — both `windowrule = float, class:^(pavucontrol)$` (and `windowrulev2` before the v2
merge) **and** `layerrule = blur, waybar`. Detect the version and pick the matching form; never mix
the two forms for one rule. See `hyprland-reference/references/window-rules.md` and
`deprecations.md`.

```ini
# Autostart (exec-once runs at launch)

# Polkit agent (pick the one chosen)
{{#if polkit_hypr}}exec-once = systemctl --user start hyprpolkitagent{{/if}}
{{#if polkit_gnome}}exec-once = /usr/lib/polkit-gnome/polkit-gnome-authentication-agent-1{{/if}}
{{#if polkit_kde}}exec-once = /usr/lib/polkit-kde-authentication-agent-1{{/if}}

# Wallpaper (pick the one chosen)
{{#if hyprpaper}}exec-once = hyprpaper{{/if}}
{{#if swww}}exec-once = swww-daemon{{/if}}

# Bar + notifications
{{#if bar}}exec-once = {{bar}}{{/if}}
{{#if notifications}}exec-once = {{notifications}}{{/if}}

# Idle + blue light + OSD
{{#if hypridle}}exec-once = hypridle{{/if}}
{{#if hyprsunset}}exec-once = hyprsunset -t 4000{{/if}}
{{#if swayosd}}exec-once = swayosd-server{{/if}}

# Trays + clipboard history
{{#if nm_applet}}exec-once = nm-applet --indicator{{/if}}
{{#if blueman}}exec-once = blueman-applet{{/if}}
{{#if clipboard}}exec-once = wl-paste --watch cliphist store{{/if}}
```

Emit only the chosen lines, without the template markers. Keep at most one polkit agent and one
wallpaper daemon.

## Companion configs (only when the matching tool is chosen)

These live in `~/.config/hypr/` alongside `hyprland.conf` but are read by their own daemons — do
**not** add `source=` lines for them. Stage them in the same staging dir so `install-config.sh`
installs and backs them up with the rest.

### hyprlock.conf

```ini
background {
    monitor =
    path = screenshot
    blur_passes = 2
    blur_size = 7
}

input-field {
    monitor =
    size = 250, 50
    outline_thickness = 2
    dots_center = true
    outer_color = rgb({{accent_hex}})    # the palette accent (literal — hyprlock is a separate daemon, can't read $accent)
    inner_color = rgb({{surface_hex}})
    font_color = rgb({{fg_hex}})
    placeholder_text = <i>Password...</i>
    fade_on_empty = true
    position = 0, -40
    halign = center
    valign = center
}

label {
    monitor =
    text = $TIME
    font_size = 64
    font_family = {{font_ui_family}}   # the UI font chosen in Area C-theme (no size suffix here)
    position = 0, 80
    halign = center
    valign = center
}
```

### hypridle.conf

```ini
general {
    lock_cmd = pidof hyprlock || hyprlock
    before_sleep_cmd = loginctl lock-session
    after_sleep_cmd = hyprctl dispatch dpms on
    inhibit_sleep = 3
}

listener {
    timeout = 150
    on-timeout = brightnessctl -s set 10%
    on-resume = brightnessctl -r
}

listener {
    timeout = 300
    on-timeout = loginctl lock-session
}

listener {
    timeout = 360
    on-timeout = hyprctl dispatch dpms off
    on-resume = hyprctl dispatch dpms on
}

listener {
    timeout = 1800
    on-timeout = systemctl suspend
}
```

If hyprlock was **not** chosen, drop the `lock_cmd` and the lock listener (or point them at the
user's locker).

### hyprpaper.conf

```ini
preload = {{wallpaper_path_or_placeholder}}
wallpaper = , {{wallpaper_path_or_placeholder}}
splash = false
```

Ask for a wallpaper path; if none, leave `~/.config/hypr/wall.png` as a placeholder and tell the
user to drop an image there.
