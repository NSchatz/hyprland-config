# look-feel — template

Renders `~/.config/hypr/conf.d/looknfeel.conf`. The file is sourced from `hyprland.conf` **after**
`colors.conf` so the palette `$vars` (`$accent`, `$accent2`, `$muted`, `$surface`, `$fg`) are in
scope. Per-app rules collected in 11i are emitted by `window-rules`, not here.

Version branches (cite [`_shared/version-matrix.md`](../../_shared/version-matrix.md)):

- `rounding_power` — **0.5x+**; emit unconditionally on `HYPR_VERSION ≥ 0.53`.
- `dwindle { pseudotile = true }` — **omit on 0.55+** (the key was removed; the `pseudo`
  dispatcher still works).
- `decoration:shadow:ignore_window` — **never emit on 0.55+** (removed; behaviour is always on).
- `misc:vfr` → `debug:vfr` — **on 0.55+ move `vfr = true` into a top-level `debug {}` block**.
- `scrolling { … }` and `general:layout = scrolling` — **core in 0.53+**, safe uncommented.
- `cursor { no_hardware_cursors = true }` — emit when `CURSOR_NO_HARDWARE_RECOMMENDED=1` (see
  `gotchas.md`).

|---|---|

|---|---|---|
| `both-on`              | true  | true  |
| `blur-on-shadows-off`  | true  | false |
| `both-off`             | false | false |

|---|---|---|---|
| `smooth` | true  | 1.0  | shipped speeds, full curve set |

## Full looknfeel.conf body

```ini
# ──────────────────────────────────────────────────────────────────────────────
# Hyprland look & feel — generated by hypr-rice.
# Palette vars come from ../colors.conf (sourced ahead of this file in hyprland.conf).
# Re-theme by editing answers.json + re-running `rice apply`, or `rice retheme`.
# ──────────────────────────────────────────────────────────────────────────────

general {
    gaps_in     = {{gaps_in}}
    gaps_out    = {{gaps_out}}
    border_size = {{border_size}}

    # Border colour. 11f default ("palette") = $accent → $accent2 gradient at 45°.
    {{#if border_color_palette}}
    col.active_border   = $accent $accent2 45deg
    {{else}}
    col.active_border   = {{border_gradient}}
    {{/if}}
    col.inactive_border = $surface

    layout            = {{layout}}        # dwindle | master | scrolling
    resize_on_border  = true
    allow_tearing     = false
}

decoration {
    rounding = {{rounding}}
    {{#if hypr_ge_0_53}}
    rounding_power = 2          # 0.5x+ — corner curve exponent; 2.3–4 for a softer "squircle"
    {{/if}}

    active_opacity   = {{opacity.active}}
    inactive_opacity = {{opacity.inactive}}

    blur {
        enabled = {{blur_enabled}}
        size    = {{blur_size}}     # frosted preset: 6
        passes  = {{blur_passes}}   # frosted preset: 2
        vibrancy = 0.1696
    }

    shadow {
        enabled       = {{shadow_enabled}}
        range         = 4
        render_power  = 3
        color         = rgba(1a1a1aee)
        # NOTE: decoration:shadow:ignore_window REMOVED in 0.55+ — do not emit on those targets.
    }
}

{{#if animations_enabled}}
animations {
    enabled = true

    bezier = easeOutQuint,   0.23, 1,    0.32, 1
    bezier = easeInOutCubic, 0.65, 0.05, 0.36, 1
    bezier = linear,         0,    0,    1,    1
    bezier = almostLinear,   0.5,  0.5,  0.75, 1
    bezier = quick,          0.15, 0,    0.1,  1

    animation = global,        1, {{a_global}},     default
    animation = border,        1, {{a_border}},     easeOutQuint
    animation = windows,       1, {{a_windows}},    easeOutQuint
    animation = windowsIn,     1, {{a_windowsIn}},  easeOutQuint, popin 87%
    animation = windowsOut,    1, {{a_windowsOut}}, linear,       popin 87%
    animation = fadeIn,        1, {{a_fadeIn}},     almostLinear
    animation = fadeOut,       1, {{a_fadeOut}},    almostLinear
    animation = fade,          1, {{a_fade}},       quick
    animation = layers,        1, {{a_layers}},     easeOutQuint
    animation = layersIn,      1, {{a_layersIn}},   easeOutQuint, fade
    animation = layersOut,     1, {{a_layersOut}},  linear,       fade
    animation = workspaces,    1, {{a_workspaces}}, almostLinear, fade
}
{{else}}
animations { enabled = false }
{{/if}}

{{layout_block}}    # one of the three layout blocks below

{{#if cursor_no_hardware}}
# Software-cursors workaround — emitted only when detect-version reports
# CURSOR_NO_HARDWARE_RECOMMENDED=1 (GPU_DRIVER nouveau or nvidia). See gotchas.md.
cursor {
    no_hardware_cursors = true
    inactive_timeout    = 0
}
{{/if}}

{{#if hypr_ge_0_55}}
# 0.55+: vfr was reclassified from misc → debug.
misc {
    disable_hyprland_logo = true
    {{#if enable_swallow}}enable_swallow = true{{/if}}
    {{#if enable_swallow}}swallow_regex  = {{swallow_regex}}{{/if}}
}
debug {
    vfr = true
}
{{else}}
misc {
    vfr                   = true   # variable frame rate — biggest idle/battery win
    disable_hyprland_logo = true
    {{#if enable_swallow}}enable_swallow = true{{/if}}
    {{#if enable_swallow}}swallow_regex  = {{swallow_regex}}{{/if}}
}
{{/if}}

{{#if groups}}
# Window groups / tabs — opted in via 11h. Themed from the palette like waybar.
group {
    col.border_active   = $accent
    col.border_inactive = $muted
    groupbar {
        enabled    = true
        font_size  = 11
        height     = 18
        gradients  = true
        text_color = $fg
        col.active   = $accent
        col.inactive = $surface
    }
}
# Binds emitted by `keybinds`: SUPER+G togglegroup; SUPER+TAB changegroupactive.
{{/if}}
```

## Layout blocks (one is substituted into `{{layout_block}}`)

### dwindle

```ini
dwindle {
    {{#if hypr_lt_0_55}}
    pseudotile = true        # REMOVED in 0.55+ — omit on those targets.
    {{/if}}
    preserve_split = true
}
```

### master

```ini
master {
    new_status  = master
    mfact       = 0.55
    orientation = {{master_orientation}}    # left | right | top | bottom | center
}
```

### scrolling — CORE in 0.53+ (not a plugin)

`scrolling` was merged into Hyprland core in 0.53. The old `hyprscrolling` / `hyprscroller`
plugins are deprecated/superseded — see [`_shared/version-matrix.md`](../../_shared/version-matrix.md).
**Safe to emit uncommented** on any target ≥ 0.53. Only plugin layouts (`hy3`) need to be
commented out until the plugin is loaded — see [`../plugins/`](../plugins/).

```ini
scrolling {
    column_width             = 0.5      # default column = fraction of monitor width
    fullscreen_on_one_column = true     # a lone column fills the screen
    focus_fit_method         = 1        # 0 center / 1 fit the focused column into view
    follow_focus             = true
    explicit_column_widths   = 0.333, 0.5, 0.667, 1.0   # cycled by colresize +conf / -conf
}
```

Scrolling binds use `layoutmsg` (`move +col`, `move -col`, `colresize +conf`, `colresize -conf`,
`fit active`, `movewindowto <dir>`); they're core dispatchers in 0.53+ and the validator allows
them uncommented. See [`_shared/dispatchers.md`](../../_shared/dispatchers.md).

## Speed multiplier (animations = `snappy`)

Multiply every `animation = ` second argument by ~0.6. Concrete values:

| target | smooth (default) | snappy |
|---|---|---|
| `global`     | 10   | 6.0  |
| `border`     | 5.39 | 3.23 |
| `windows`    | 4.79 | 2.87 |
| `windowsIn`  | 4.1  | 2.46 |
| `windowsOut` | 1.49 | 0.89 |
| `fadeIn`     | 1.73 | 1.04 |
| `fadeOut`    | 1.46 | 0.88 |
| `fade`       | 3.03 | 1.82 |
| `layers`     | 3.81 | 2.29 |
| `layersIn`   | 4    | 2.4  |
| `layersOut`  | 1.5  | 0.9  |
| `workspaces` | 1.94 | 1.16 |

For window-group anim speed, `smooth ≈ 7`, `snappy ≈ 4`.

## What does NOT belong here

- The per-app `windowrule { ... }` lines themselves — they're emitted by `window-rules` from the
  `look_feel.per_app_rules[]` slice. This file just carries the user's intent.
- The `SUPER+G` / `SUPER+TAB` / `SUPER+SHIFT+B` binds — emitted by `keybinds`.
- Workspace smart-gaps rules — owned by `monitors`.
- `general:layout = hy3` (or any other plugin layout) — gated through `components/plugins/`. Never
  emit a plugin layout uncommented; it HARD-ERRORS the reload.
