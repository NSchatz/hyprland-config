# window-rules — template

Renders to `~/.config/hypr/windowrules.conf`, sourced from `hyprland.conf` (the `source =` line
lives in `../keybinds/template.md`, which owns the top-level file).

Version branches are dictated by `_shared/version-matrix.md`:

- **0.53+** → `windowrule` block form (shown below). The legacy v1 single-line
  `windowrule = float, class:^(x)$` form **stopped parsing in 0.53** because matchers now require
  the `match:` prefix and effects must carry an explicit value. The modern single-line form
  (`windowrule = float, match:class kitty`) still works, but emit the block form on 0.53+ to
  match the shipped default. `windowrulev2 = …` is hard-rejected with a deprecation error.
- **0.54+** → `layerrule` block form is the recommended emission. The bare-keyword
  `layerrule = blur, waybar` form is rejected at parse time (`invalid field blur: missing a
  value`) and fails the whole reload — see `gotchas.md`. The modern single-line
  (`layerrule = blur on, match:namespace waybar`) parses, but we emit the block form because
  that's what the shipped 0.54.3 default uses and it's where the wiki points users.
- **pre-0.53** → fall back to legacy single-line `windowrule = …` / `windowrulev2 = …` and
  single-line `layerrule = blur, <ns>`. Don't mix forms inside one rule.

## Full template (0.53+, with 0.54+ layerrule blocks)

```ini
# windowrules.conf — generated by rice

# ------------------------------------------------------------
# Shipped defaults (broadly useful — every rice should inherit)
# ------------------------------------------------------------

windowrule {
    name = suppress-maximize
    match:class = .*
    suppress_event = maximize
}

windowrule {
    name = fix-xwayland-drags
    match:class = ^$
    match:title = ^$
    match:xwayland = true
    match:float = true
    match:fullscreen = false
    match:pin = false
    no_focus = true
}

# ------------------------------------------------------------
# Float common utility dialogs
# ------------------------------------------------------------

windowrule {
    name = float-utilities
    match:class = ^(pavucontrol|nm-connection-editor|blueman-manager)$
    float = yes
}

# ------------------------------------------------------------
# Picture-in-Picture: float + pin so it survives workspace switches
# ------------------------------------------------------------

windowrule {
    name = pip
    match:title = ^(Picture-in-Picture)$
    float = yes
    pin = yes
}

# ------------------------------------------------------------
# Idle-inhibit while fullscreen (video / games don't trigger idle)
# ------------------------------------------------------------

windowrule {
    name = idleinhibit-fullscreen
    match:fullscreen = true
    idle_inhibit = fullscreen
}

# ------------------------------------------------------------
# Smart gaps — pair with `workspace = w[tv1], gapsout:0, gapsin:0`
# in monitors.conf. Only emitted when monitors.workspace_rules.smart_gaps is true.
# ------------------------------------------------------------
{{#if monitors.workspace_rules.smart_gaps}}
windowrule {
    name = smartgaps-bordersize
    match:float = false
    match:workspace = w[tv1]
    border_size = 0
}
windowrule {
    name = smartgaps-rounding
    match:float = false
    match:workspace = w[tv1]
    rounding = 0
}
{{/if}}

# ------------------------------------------------------------
# App → workspace pins (group 1f, monitors.pin_apps)
# `silent` so launches don't yank focus from the user's current workspace.
# ------------------------------------------------------------
{{#each monitors.pin_apps as |ws class|}}
windowrule {
    name = pin-{{class}}
    match:class = ^({{class}})$
    workspace = {{ws}} silent
}
{{/each}}

# ------------------------------------------------------------
# Per-app rules (group 11i, look_feel.per_app_rules)
# Effects are emitted verbatim from the answer — float/opacity/no_blur/workspace/etc.
# ------------------------------------------------------------
{{#each look_feel.per_app_rules}}
windowrule {
    name = app-{{this.class}}
    match:class = ^({{this.class}})$
{{#each this.effects}}
    {{this}}
{{/each}}
}
{{/each}}

# ------------------------------------------------------------
# Layer-shell blur (0.54+ block form — see gotchas.md for the hard break)
# ------------------------------------------------------------
{{#if waybar.enabled}}
layerrule {
    name = blur-waybar
    match:namespace = waybar
    blur = true
}
{{/if}}
{{#if launcher.is_layer}}
layerrule {
    name = blur-{{launcher.namespace}}
    match:namespace = {{launcher.namespace}}
    blur = true
}
{{/if}}
{{#if notifications.namespace}}
layerrule {
    name = blur-{{notifications.namespace}}
    match:namespace = {{notifications.namespace}}
    blur = true
    ignore_alpha = 0.0
}
{{/if}}
```

## Pre-0.53 fallback (target detected as older)

If `HYPR_VERSION < 0.53`, emit the legacy single-line forms instead. **Don't mix forms inside one
rule.**

```ini
# defaults
windowrule = suppressevent maximize, class:.*
windowrulev2 = nofocus, class:^$, title:^$, xwayland:1, floating:1, fullscreen:0, pinned:0

# float utilities
windowrule = float, class:^(pavucontrol|nm-connection-editor|blueman-manager)$

# PiP
windowrule = float, title:^(Picture-in-Picture)$
windowrule = pin,   title:^(Picture-in-Picture)$

# idle inhibit while fullscreen
windowrulev2 = idleinhibit fullscreen, fullscreen:1

# pinned apps
windowrulev2 = workspace 9 silent, class:^(Spotify)$

# layer blur (single-line form is only valid pre-0.54)
layerrule = blur, waybar
layerrule = blur, rofi
```

## What does NOT belong here

- `source = ~/.config/hypr/windowrules.conf` → that line lives in `hyprland.conf`, owned by
  `../keybinds/template.md`.
- `workspace = N, monitor:DP-1, persistent:true, on-created-empty:…` → that is a **workspace rule**,
  owned by `../monitors/template.md` (`monitors.conf`). Only the `windowrule`/`layerrule` half of
  the workspace-rules answer lands here.
- `bordercolor` overrides keyed to a class → live in `../look-feel/` (borders block) so the value
  resolves to a palette variable.
- The `SUPER+SHIFT+B` blur-toggle bind (look-feel 11j) → `../keybinds/template.md` (`binds.conf`).
