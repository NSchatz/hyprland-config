# lock-screen — template

The component generates one file: `~/.config/hypr/hyprlock.conf`.

**Colors are LITERAL hex** — hyprlock is a separate daemon and **cannot read Hyprland `$vars`**
from `colors.conf`. The engine substitutes `{{accent}}`, `{{surface}}`, `{{fg}}`, `{{green}}`,
`{{red}}`, `{{bg}}` from `palette.conf` at generate-time. See [`gotchas.md`](./gotchas.md) and
[`_shared/colors-contract.md`](../../_shared/colors-contract.md).

The `font_family` substitution takes the UI font **family only** — strip the size suffix from
`palette.conf`'s `font_ui` (`"Inter 11"` → `Inter`). hyprlock's own `font_size` keys set the
display size per widget.

## Output file: `~/.config/hypr/hyprlock.conf`

The structure is fixed: `general` block, `background` block, `input-field` block, optional clock
`label`(s), optional `auth { fingerprint {} }` block. Widgets draw in declaration order.

### Full template

```ini
# ~/.config/hypr/hyprlock.conf — generated by rice
# Colors are LITERAL hex; hyprlock can't read Hyprland $vars (see gotchas.md).
$font = {{font_ui_family}}            # UI family only, no size suffix

general {
    hide_cursor = true
    grace = 0                         # seconds the lock can be dismissed without a password
    ignore_empty_input = true         # Enter on empty field doesn't count as a failed attempt
}

# ---------- background ----------
{{#if background == "blurred-screenshot"}}
background {
    monitor =
    path = screenshot
    blur_passes = 3
    blur_size = 7
    brightness = 0.70                 # dim so the clock/pill pop
    vibrancy = 0.17
}
{{/if}}
{{#if background == "wallpaper"}}
background {
    monitor =
    path = {{wallpaper_path}}
    blur_passes = 1
    blur_size = 5
}
{{/if}}
{{#if background == "solid"}}
background {
    monitor =
    color = rgb({{bg}})
}
{{/if}}

# ---------- input-field ----------
{{#if input_pill == "accent-outlined"}}
input-field {
    monitor =
    size = 280, 55
    rounding = -1                     # full pill
    outline_thickness = 2
    dots_size = 0.33
    dots_spacing = 0.2
    dots_center = true
    fade_on_empty = false
    outer_color = rgb({{accent}})
    inner_color = rgb({{surface}})
    font_color  = rgb({{fg}})
    check_color = rgb({{green}})
    fail_color  = rgb({{red}})
    placeholder_text = <i>Password…</i>
    font_family = $font
    position = 0, -120
    halign = center
    valign = center
}
{{/if}}
{{#if input_pill == "underline"}}
# "Minimal underline" — still a VISIBLE thin pill. NEVER a 6px sliver
# with outline_thickness = 0 and fade_on_empty = true (see gotchas.md).
input-field {
    monitor =
    size = 280, 50
    rounding = 0
    outline_thickness = 1
    dots_size = 0.33
    dots_center = true
    fade_on_empty = false
    outer_color = rgb({{accent}})
    inner_color = rgba(00000000)      # transparent; underline reads as a hairline
    font_color  = rgb({{fg}})
    check_color = rgb({{green}})
    fail_color  = rgb({{red}})
    placeholder_text = <i>Password…</i>
    font_family = $font
    position = 0, -120
    halign = center
    valign = center
}
{{/if}}
{{#if input_pill == "hidden"}}
# "Hidden until typing" — fade_on_empty IS true, BUT once the user types
# the field is fully visible (real height, accent outline, dots).
input-field {
    monitor =
    size = 280, 50
    rounding = -1
    outline_thickness = 1
    dots_size = 0.33
    dots_center = true
    fade_on_empty = true
    fade_timeout = 1500
    outer_color = rgb({{accent}})
    inner_color = rgb({{surface}})
    font_color  = rgb({{fg}})
    check_color = rgb({{green}})
    fail_color  = rgb({{red}})
    placeholder_text =                 # nothing to hint while hidden
    font_family = $font
    position = 0, -120
    halign = center
    valign = center
}
{{/if}}

# ---------- clock ----------
{{#if clock == "large"}}
label {
    monitor =
    text = $TIME
    font_size = 96
    font_family = $font
    color = rgb({{fg}})
    position = 0, 160
    halign = center
    valign = center
}
label {
    monitor =
    text = cmd[update:60000] date +"%A, %d %B"
    font_size = 22
    font_family = $font
    color = rgb({{fg}})
    position = 0, 90
    halign = center
    valign = center
}
{{/if}}
{{#if clock == "time-only"}}
label {
    monitor =
    text = $TIME
    font_size = 96
    font_family = $font
    color = rgb({{fg}})
    position = 0, 120
    halign = center
    valign = center
}
{{/if}}
{{#if clock == "none"}}
# (no clock label)
{{/if}}

# ---------- optional fingerprint ----------
{{#if fingerprint}}
auth {
    fingerprint {
        enabled = true
        # Falls back to password if no reader / no enrolled finger.
        # Requires fprintd + an enrolled finger (see packages.md).
    }
}
{{/if}}
```

## Substitution map

| Placeholder        | Source                           | Notes |
|---|---|---|
| `{{font_ui_family}}` | `palette.conf` `font_ui` minus the size suffix | `"Inter 11"` → `Inter`. |
| `{{wallpaper_path}}` | `wallpaper.path` from `answers.json` | Only when `background = wallpaper`. |
| `{{accent}}`         | `palette.conf` `accent`           | Bare hex (no `#`). |
| `{{surface}}`        | `palette.conf` `surface`          | Bare hex. |
| `{{fg}}`             | `palette.conf` `fg`               | Bare hex. |
| `{{bg}}`             | `palette.conf` `bg`               | Bare hex; used only for the `solid` background. |
| `{{green}}`          | `palette.conf` `green`            | Bare hex; `check_color`. |
| `{{red}}`            | `palette.conf` `red`              | Bare hex; `fail_color`. |
